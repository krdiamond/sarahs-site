# Sarah Fensom site (HTML-ONLY branch)

Vanilla **HTML + Tailwind + JS** (Vite, no Vue). Sheet-driven Contact / Events / Work / Icons / Favicon.

> **Preview branch only.** Do not merge to `main` or deploy to GitHub Pages from this branch. Live site stays on `main`.

## Local preview

```bash
git fetch origin
git checkout HTML-ONLY
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173/sarahs-site/`).

Production-style local build:

```bash
npm run build
npm run preview
```

See also the Project store doc: `docs/html-only-preview.md`.
